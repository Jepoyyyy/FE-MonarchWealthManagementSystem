Monarch Wealth Management System - First Login Performance

Date: 2026-07-27

Target Pages: Dashboard, Assets, Goals

Optimization Focus: First login experience and page navigation speed

Effort Level: Medium

Executive Summary

Problem: The application runs extremely slowly on first login, particularly on the Dashboard, Assets, and Goals pages. Users experience significant delays due to multiple sequential API calls, duplicate data fetching, and lack of data caching.

Root Causes:

  • 9+ API calls made across Dashboard, Assets, and Goals pages during first login
  • Triple fetching of portfolio data (Layout, Assets page, Goals page)
  • No caching strategy - every navigation triggers fresh API calls
  • Sequential loading - pages don't parallelize independent data fetches
  • No coordination between Layout and child components for data initialization

Expected Impact:

70% reduction in API calls 3-5x faster page loads Instant navigation after initial load

Task 2: Implement Store-Level Caching with TTL

Priority: HIGH Estimated Time: 2-3 hours Impact: Instant page navigation, 80% fewer API calls

Objective: Add Time-To-Live (TTL) based caching to Zustand stores so data is only refetched when stale, not on every page navigation.

2.1: Update Portfolio Store with Caching

File: app/features/assets/portfolio.store.ts

Implementation Steps:

  • Add lastFetched: number | null field to PortfolioState interface
  • Define CACHE_TTL = 5 * 60 * 1000 (5 minutes)
  • Add force?: boolean parameter to fetchPortfolio() function
  • Implement cache check logic before fetching
  • Use Zustand persist middleware for localStorage persistence
  • Update lastFetched = Date.now() after successful fetch

Cache Logic:

  • If loading === true, return early (fetch already in progress)
  • If !force && lastFetched && (Date.now() - lastFetched) < CACHE_TTL, return early (data is fresh)
  • Otherwise, proceed with fetch and update lastFetched
// Key changes in portfolio.store.ts import { persist } from 'zustand/middleware'; const CACHE_TTL = 5 * 60 * 1000; // 5 minutes export const usePortfolioStore = create<PortfolioState>()( persist( (set, get) => ({ // ... existing state lastFetched: null, fetchPortfolio: async (force = false) => { const { lastFetched, loading } = get(); if (loading) return; const now = Date.now(); if (!force && lastFetched && (now - lastFetched) < CACHE_TTL) { return; // Use cached data } // ... fetch logic set({ /* data */, lastFetched: Date.now() }); }, }), { name: 'portfolio-storage' } ) );
